🚀 Yeni Müşteri Kurulum Rehberi

Spormanage Multi-Tenant Deployment Guide

Bu dokümanda yeni bir müşteri için Coolify üzerinde uygulama kurulumu adım adım anlatılmaktadır.

📌 Genel Mimari:
✅ Tek PostgreSQL servisi (paylaşımlı)
✅ Her müşteri için ayrı database
✅ Her müşteri için ayrı application instance
✅ Aynı Docker image, farklı environment variable'lar

1️⃣ PostgreSQL Database Oluşturma

1Coolify PostgreSQL Terminaline Bağlan

Coolify → Servers → PostgreSQL Resource → Terminal

psql -U postgres

2Yeni Database Oluştur

Örnek: kulturpay müşterisi için

CREATE DATABASE kulturpay;

Kontrol:

\l

3Çık

\q

2️⃣ Coolify'de Yeni Application Oluşturma

1Yeni Resource Ekle

Coolify → Projects → Aidat_Takip → + New → Application

  • Name: kulturpay (veya müşteri adı)
  • Git Repository: https://github.com/celebigilfatih/spormanage.git
  • Branch: main
  • Build Pack: nixpacks

2Domain Ayarları

Configuration → Domains

  • Domain: kulturpay.spormanage.com.tr
  • ✅ HTTPS aktif

5️⃣ Admin Kullanıcı Oluşturma

1Bcrypt Hash Oluştur

Local bilgisayarında (project klasöründe):

node -p "require('bcryptjs').hashSync('Kultur2025Pay!!', 10)"

Çıktı örneği:

$2b$10$abc123xyz789...

Bu hash'i kopyala.

2PostgreSQL'e Bağlan

Coolify → kulturpay app → Terminal

psql "postgresql://postgres:Thor.7485-aidat@f4gwswcwo48cww88c80s8sg8:5432/kulturpay"

3Admin Kullanıcı Ekle

INSERT INTO users (id, email, password, name, phone, role, "isActive", "createdAt", "updatedAt")
VALUES (
  'admin-kultur-001',
  'kulturpay@spormanage.com.tr',
  '$2b$10$abc123xyz789...',  -- Yukarıda oluşturduğun hash
  'Kültür Admin',
  '+90 555 123 4567',
  'ADMIN',
  true,
  NOW(),
  NOW()
);

Başarılı olursa: INSERT 0 1

4Kontrol Et

SELECT id, email, name, role, "isActive" 
FROM users 
WHERE email = 'kulturpay@spormanage.com.tr';

Kullanıcıyı görmelisin.

5Çık

\q

🔧 Sorun Giderme

❌ Login 401 Hatası

Çözüm:
1. Coolify Logs'ta [LOGIN-DEBUG] satırlarını kontrol et
2. Email'in DB'de olduğunu doğrula: SELECT email FROM users;
3. Password hash'in doğru olduğundan emin ol

❌ Database Connection Error

Çözüm:
1. DATABASE_URL'i kontrol et
2. PostgreSQL hostname'in doğru olduğundan emin ol: f4gwswcwo48cww88c80s8sg8
3. Database'in mevcut olduğunu doğrula: \l

❌ Migration Failed: Prisma 7 Error

Çözüm:
Startup script zaten prisma@6.17.1 kullanıyor, sorun olmamalı.
Eğer olursa Dockerfile'da düzgün kopyalandığından emin ol.
